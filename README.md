# Drowsiness-Model-using-opencv
A non‑intrusive, real‑time computer‑vision system that detects driver drowsiness by monitoring eye‑state (“open” vs. “closed”) and emits audible/visual alerts when signs of fatigue are detected. Built with PyTorch, YOLOv5, and OpenCV, deployable on both desktop and Raspberry Pi.



Features:-

- Real‑time inference at ≥10 FPS on standard hardware  
- High‑accuracy eye‑state classification via a custom YOLOv5 model  
- Configurable alerts (beep, on‑screen message)  
- Lightweight & portable: for embedded devices (e.g. Raspberry Pi)  
- Modular codebase: for easy extension (head‑pose, yawn detection, etc.)
